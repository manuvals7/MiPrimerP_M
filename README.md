# Mi Primer Proyecto Android

Proyecto desarrollado en Android Studio que cumple con los siguientes requerimientos:
1. **Soporte para 4 idiomas:** Español (`values`), Inglés (`values-en`), Francés (`values-fr`) y Alemán (`values-de`).
2. **Fondo redimensionable Nine-Patch:** Implementación de `fondo_android.9.png` en `res/drawable/` para evitar deformaciones de la mascota de Android en distintos tamaños de pantalla.
3. **Soporte a múltiples pantallas y orientaciones:** Layouts adaptables (`layout/` y `layout-land/`) y dimensiones escalables (`values/dimens.xml` y `values-sw600dp/dimens.xml`).
